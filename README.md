# Udesel
A free Windows application for downloading Udemy courses.

A modern Windows desktop application built with Python and PyQt6.

## About

Udesel is a lightweight Windows desktop application designed to help users manage and download Udemy course content that they are authorized to access.

The application provides a clean and user-friendly graphical interface while keeping the project lightweight and easy to maintain.

## Features

- Download enrolled Udemy course content
- Graphical user interface
- Custom application icons
- Fast and lightweight
- Standalone Windows executable
- Easy configuration
- Native Windows experience
- Responsive interface

## Download

You don't need to install Python to run Udesel.

### Installation

1. Download the latest `.exe` file from the Releases page.
4. Run `Udesel.exe`.

> Note: Windows Defender or SmartScreen may display a warning because the application is not digitally signed. If you trust the source, select **More info → Run anyway**.

## Requirements

The standalone Windows release does not require Python or PyQt6 to be installed separately.
